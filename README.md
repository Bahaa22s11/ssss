# 📝 Todo List Application

تطبيق قائمة المهام مع حفظ محلي في JSON

## ✨ المميزات
- ✅ إضافة مهام جديدة
- ✅ حذف المهام
- ✅ تعليم المهام كـ مكتملة
- ✅ تصنيفات للمهام
- ✅ تاريخ الاستحقاق
- ✅ البحث والتصفية
- ✅ حفظ تلقائي في JSON

## 🛠️ التقنيات
- **Language**: C#
- **Framework**: WPF (.NET Framework 4.7.2)
- **Storage**: JSON Local Files
- **NuGet**: Newtonsoft.Json

## 📋 المتطلبات
- Visual Studio 2019+
- .NET Framework 4.7.2+

## 🚀 البدء السريع
1. Clone المستودع
2. افتح في Visual Studio
3. ثبت NuGet packages
4. اضغط F5 للتشغيل
